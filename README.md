# homebrew-tap

Homebrew formulae and casks for [amjadjibon](https://github.com/amjadjibon)'s tools.

## Install

```bash
brew install amjadjibon/tap/snaptext
brew install --cask amjadjibon/tap/duofx
```

Or tap once and install by name afterwards:

```bash
brew tap amjadjibon/tap
brew install snaptext
brew install --cask duofx
```

## Formulae

| Formula | Description |
| --- | --- |
| [snaptext](https://github.com/amjadjibon/snaptext) | Local OCR for macOS: read text from images, the clipboard, or the screen |

## Casks

| Cask | Description |
| --- | --- |
| [duofx](https://github.com/amjadjibon/DuoFX) | Menu-bar app that animates the desktop as the MacBook lid closes |

## Opening DuoFX the first time

DuoFX is not notarized yet, and Homebrew always quarantines what a cask
installs. macOS therefore refuses the first launch and reports that the app "is
damaged and can't be opened". Nothing is wrong with the download; that is
Gatekeeper declining an app Apple has not notarized. Clear the flag once:

```bash
xattr -dr com.apple.quarantine /Applications/DuoFX.app
```

Or open **System Settings → Privacy & Security** after the failed launch and
choose **Open Anyway**. Only the first launch needs this.

This does not apply to `snaptext`: a formula installs a bare binary that
Homebrew fetches with `curl`, which never sets the quarantine flag.

## Upgrade

```bash
brew update
brew upgrade snaptext
brew upgrade --cask duofx
```

## Uninstall

```bash
brew uninstall snaptext
brew uninstall --cask duofx
brew untap amjadjibon/tap
```

## Notes

Formulae and casks here ship prebuilt artifacts from each project's GitHub
release, and are generated by each project's release script — edit them there,
not here.
