# homebrew-tap

Homebrew formulae for [amjadjibon](https://github.com/amjadjibon)'s tools.

## Install

```bash
brew install amjadjibon/tap/snaptext
```

Or tap once and install by name afterwards:

```bash
brew tap amjadjibon/tap
brew install snaptext
```

## Formulae

| Formula | Description |
| --- | --- |
| [snaptext](https://github.com/amjadjibon/snaptext) | Local OCR for macOS: read text from images, the clipboard, or the screen |

## Upgrade

```bash
brew update
brew upgrade snaptext
```

## Uninstall

```bash
brew uninstall snaptext
brew untap amjadjibon/tap
```

## Notes

The formulae here ship prebuilt universal binaries from each project's GitHub
release. Homebrew downloads them with `curl`, which does not set the quarantine
flag, so there is no Gatekeeper prompt to clear even though the binaries are not
notarized.

Formulae are generated by each project's release script — edit them there, not
here.
